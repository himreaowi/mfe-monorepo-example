# My Profile (`@org/internet-my-profile`)

Remote of the **internet** zone (`access: private`). Federation name `internet_my_profile`,
dev port `3203`. Generated by `pnpm gen:remote internet my-profile`.

The internet shell mounts it at `/my-profile/*` (entry in the shell's `remotes.json`) and loads
`./App` at runtime from the URL in `mfe-manifest.json`.

## In this example

Private remote (`access: private`): the shell renders it only after sign-in and does not download
it before. Shows the signed-in user's profile from `GET /profile/me` and saves notification
choices with `PUT /profile/me/preferences`, sending the session's CSRF token from `useAuth()`.
A 401 from the API calls `useAuth().refresh()`. Standalone there is no session, so saving answers
403 (no CSRF token): use the shell for that flow.

## Commands

| Command                                          | What                                                               |
| ------------------------------------------------ | ------------------------------------------------------------------ |
| `pnpm --filter @org/internet-my-profile dev`     | Standalone on http://localhost:3203 (mock host props)              |
| `pnpm dev:internet` (repo root)                  | Inside the shell: http://localhost:3200/my-profile                 |
| `pnpm --filter @org/internet-my-profile build`   | Production build in `dist/` (`mf-manifest.json`, `remoteEntry.js`) |
| `pnpm --filter @org/internet-my-profile preview` | Serve `dist/` on port 3203 (CORS enabled)                          |
| `lint` / `typecheck` / `test`                    | ESLint, `tsc`, Jest                                                |

## Rules

- `src/app/RemoteApp.tsx` is the exposed module (`./App`). It must **not** import global styles
  (`@org/design-tokens/global.scss`) or register a service worker: the shell owns the page. Only
  `src/bootstrap.tsx` (standalone) does that.
- Routes in `src/app/routes.tsx` are relative. Link between pages with `useRemotePath()` from
  `@org/mf-runtime/remote` (gives `/my-profile/details` in the shell, `/details` standalone).
- Never import another remote or a shell (`pnpm check` and ESLint module boundaries fail).
- Dependencies: see `docs/adding-dependencies.md` (catalog vs app-local).

## Layout

```
src/
  main.tsx            import('./bootstrap')
  bootstrap.tsx       standalone only: global styles + <StandaloneApp />
  app/                RemoteApp (exposed), apps (createRemoteApp), routes, standaloneProps
  features/profile/   api/, hooks/, types/, __fixtures__/, components/ (one folder per
                      component: MyProfile/, ProfileDetails/, PreferencesForm/)
  layouts/            StandaloneLayout (MainLayout chrome, standalone only)
  pages/              OverviewPage, DetailsPage, NotFoundPage
  core/constants/     app, routePaths, apiRoutes
  services/           http client (base URL from host settings)
```
