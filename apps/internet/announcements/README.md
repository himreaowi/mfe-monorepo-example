# Announcements (`@org/internet-announcements`)

Remote of the **internet** zone (`access: public`). Federation name `internet_announcements`,
dev port `3202`. Generated by `pnpm gen:remote internet announcements`.

The internet shell mounts it at `/announcements/*` (entry in the shell's `remotes.json`) and loads
`./App` at runtime from the URL in `mfe-manifest.json`.

## In this example

Announcements, newest first, and a page per announcement (`/announcements/<id>`). The body is
plain-text paragraphs; no HTML from the API is rendered.

## Commands

| Command                                             | What                                                               |
| --------------------------------------------------- | ------------------------------------------------------------------ |
| `pnpm --filter @org/internet-announcements dev`     | Standalone on http://localhost:3202 (mock host props)              |
| `pnpm dev:internet` (repo root)                     | Inside the shell: http://localhost:3200/announcements              |
| `pnpm --filter @org/internet-announcements build`   | Production build in `dist/` (`mf-manifest.json`, `remoteEntry.js`) |
| `pnpm --filter @org/internet-announcements preview` | Serve `dist/` on port 3202 (CORS enabled)                          |
| `lint` / `typecheck` / `test`                       | ESLint, `tsc`, Jest                                                |

## Rules

- `src/app/RemoteApp.tsx` is the exposed module (`./App`). It must **not** import global styles
  (`@org/design-tokens/global.scss`) or register a service worker: the shell owns the page. Only
  `src/bootstrap.tsx` (standalone) does that.
- Routes in `src/app/routes.tsx` are relative. Link between pages with `useRemotePath()` from
  `@org/mf-runtime/remote` (gives `/announcements/details` in the shell, `/details` standalone).
- Never import another remote or a shell (`pnpm check` and ESLint module boundaries fail).
- Dependencies: see `docs/adding-dependencies.md` (catalog vs app-local).

## Layout

```
src/
  main.tsx            import('./bootstrap')
  bootstrap.tsx       standalone only: global styles + <StandaloneApp />
  app/                RemoteApp (exposed), apps (createRemoteApp), routes, standaloneProps
  features/announcements/  api/, hooks/, types/, __fixtures__/, components/ (one folder
                      per component: AnnouncementList/, AnnouncementDetail/)
  layouts/            StandaloneLayout (MainLayout chrome, standalone only)
  pages/              OverviewPage, DetailsPage, NotFoundPage
  core/constants/     app, routePaths, apiRoutes
  services/           http client (base URL from host settings)
```
