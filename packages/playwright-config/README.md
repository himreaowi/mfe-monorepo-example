# @org/playwright-config

Shared Playwright setup for the **zone e2e suites**. Each zone's suite lives in its shell
(`apps/<zone>/shell-<zone>/e2e/`, generated by `pnpm gen:shell`) and covers the shell and every
remote of the zone. Full guide: [docs/testing.md](../../docs/testing.md).

```ts
// apps/<zone>/shell-<zone>/playwright.config.ts
import { createZoneConfig } from '@org/playwright-config';

export default createZoneConfig({ shellDir: import.meta.dirname });
```

## `createZoneConfig({ shellDir, workers?, timeout?, webServerTimeout?, command?, extraHealthUrls?, overrides? })`

| Setting       | Value                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Projects      | `desktop` (Desktop Chrome, 1280×720) and `mobile` (Chromium, **375×812**, touch)                                                                                                                                                                                                                                                                                                                    |
| `webServer`   | `pnpm run dev:<zone>` in the workspace root (shell + every remote of the zone + the zone's mock API and mock vendor), waits for the shell URL. `reuseExistingServer` locally (an open `pnpm dev:<zone>` is used), never in CI. Stopped with SIGTERM afterwards; `pnpm dev:<zone>`'s launcher then prints one `dev servers stopped (SIGTERM, expected)` line instead of Nx's failure-looking summary |
| Global setup  | waits until every remote's `mf-manifest.json` from `mfe-manifest.dev.json`, local vendor bundles, `<settings.apiBaseUrl>/health` when that API is on localhost (the mock API) and every `extraHealthUrls` entry answer (status < 500), so no test races a server that is still starting. Fails with the list of URLs that never answered                                                            |
| `overrides`   | merged last: `metadata` **deep-merged** (arrays such as `mfeWaitFor` concatenated), `use` / `expect` merged one level deep, any other key replaces the default (`mergeZoneConfig(config, overrides)`)                                                                                                                                                                                               |
| `baseURL`     | `http://localhost:<shell mfe.port>`                                                                                                                                                                                                                                                                                                                                                                 |
| CI (`CI` set) | `retries: 2`, `forbidOnly`, reporters `list` + `junit` (`test-results/junit.xml`) + `html` (`playwright-report/`), trace on first retry                                                                                                                                                                                                                                                             |
| Local         | `retries: 0`, reporters `list` + `html`, trace kept on failure                                                                                                                                                                                                                                                                                                                                      |
| Workers       | 2 (dev servers on one machine; `MFE_E2E_WORKERS=<n>` to change)                                                                                                                                                                                                                                                                                                                                     |

Environment: `CI`, `MFE_E2E_WORKERS`, `MFE_E2E_SKIP_WEBSERVER=1` (servers are managed outside
Playwright), `MFE_E2E_WAIT_MS` (global setup wait, default 180000).

## `@org/playwright-config/test`

```ts
import {
  test,
  expect,
  checkA11y,
  useTheme,
  loadZone,
} from '@org/playwright-config/test';
```

| Export                                                                                                                                                                                 | What                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `test`                                                                                                                                                                                 | Playwright `test` + auto fixture `consoleErrors`: **fails the test if the page logged a `console.error`, threw an uncaught exception or had a failed HTTP request** (status ≥ 400 or network error, recorded with its URL from `response` / `requestfailed`; Chromium's URL-less "Failed to load resource" line is skipped). Options (`test.use(...)`): `allowedConsoleErrors: RegExp[]` (text, or "text (url)"), `allowedHttpErrors: ({ url?, status?, method? } \| RegExp)[]`. Per test: `consoleErrors.allow(re)`, `consoleErrors.allowHttp({ url: /\/api\/items$/, status: 422 })` |
| `checkA11y(page, { include?, exclude?, disableRules?, tags? })`                                                                                                                        | axe-core with `WCAG_TAGS` (2.0/2.1/2.2, A + AA); fails with one line per failing node (rule, impact, target, fix, help URL). Open shadow roots are scanned                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `useTheme(page, 'light' \| 'dark')`                                                                                                                                                    | the next pages start in that theme (stored preference `mfe-theme` + `prefers-color-scheme`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `loadZone(shellDir)`                                                                                                                                                                   | the zone from the shell's files: `shellUrl`, `authMock`, `apiBaseUrl`, `mockApi`, `waitFor`, `remotes[]` (registry entry + `entry`, `origin`, `standaloneUrl`, `vendor`, `mockVendor`)                                                                                                                                                                                                                                                                                                                                                                                                 |
| `WCAG_TAGS`, `THEME_STORAGE_KEY`, `formatViolations`, `isMockVendor`, `localHealthUrl`, `matchesHttpAllowance`, `MOCK_VENDOR_ORIGINS`, `MOCK_API_ORIGINS`, `TOOL_PORTS`, `waitForUrls` | building blocks (`TOOL_PORTS`, `readToolPorts(root)`, `ZONE_TOOL_RANGES` from `@org/playwright-config/zone`: tool ports read from the root `package.json` `mfe.tools`, the same source as `toolPort()` in tools/scripts; a test there compares them)                                                                                                                                                                                                                                                                                                                                   |

`@playwright/test` and `@axe-core/playwright` are peer dependencies (catalog versions); the
shell lists them in its devDependencies. Browsers: `pnpm --filter <shell> exec playwright install chromium`
(CI: `--with-deps`).

Tests: `pnpm --filter @org/playwright-config test` (node --test).
